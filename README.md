# NotchMan releases

Downloads for [NotchMan](https://notchman.com), the small stuff of your day in your Mac's notch.

- **Latest DMG:** see the [Releases](https://github.com/pratyagarwal/notchman-releases/releases/latest) page.
- **Requirements:** macOS 14 Sonoma or later.
- **Updates:** the app checks this repo's `appcast.xml` and offers updates in place.

Source is private. Bugs and feature requests: hello@notchman.com.
